# Bubble Sort console application

Create a .NET 10 solution containing a console application and an xUnit test project.

The console application must contain a separate Bubble Sort implementation that sorts an integer array in ascending order. Do not use any built-in or framework sorting APIs, including `Array.Sort`, `List<T>.Sort`, LINQ `OrderBy`/`Order`, or equivalent sorting helpers.

Add exactly these seven xUnit test cases:

1. an empty array;
2. a single-element array;
3. an already sorted array;
4. a reverse-sorted array;
5. an array containing duplicates;
6. an array containing negative values;
7. a mixed unsorted array.

Integrate both projects into the solution. The solution must build successfully and all seven tests must pass.
