# IDD Intent

Read `INDEX.md` first, then resolve relevant stable `IDD-NNNN` identifiers to
the unique current `IDD-NNNN.type-short-title.md` documents in this directory.
Current numbered documents own product behavior; the index is discovery metadata.
The first heading of each document starts with its identifier and document type.
Implementation tasks, progress and verification commands do not belong in Intent.
Previous versions are available in Git history. There is no Intent archive.
