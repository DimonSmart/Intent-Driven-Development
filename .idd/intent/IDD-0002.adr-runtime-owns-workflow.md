# IDD-0002.adr-runtime-owns-workflow

## Status

Superseded by IDD-0006

## Context

This ADR introduced a deterministic .NET Factory runtime that owned workflow
state, retries, verification, recovery, and semantic execution transitions.

That architecture accumulated operational machinery around a semantic problem
whose essential shape is planner -> isolated worker -> planner.

## Historical Decision

The runtime owned deterministic Factory workflow and mediated semantic agents.

## Superseded By

IDD-0006 replaces this decision with native-agent orchestration and deliberately
at-least-once execution. This file remains only as historical durable decision
context.
