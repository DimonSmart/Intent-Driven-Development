# IDD-0004.adr-blocking-factory-transport

## Status

Superseded by IDD-0006

## Context

This ADR introduced a blocking Factory transport to prevent token-expensive
model-driven status polling while the former packaged runtime executed.

## Historical Decision

Adapters used a blocking transport around the Factory runtime; Codex used a
bundled MCP transport and Claude could use the packaged CLI.

## Superseded By

IDD-0006 removes the Factory transport layer. Native child-agent delegation and
native blocking/event-driven waiting now provide the required no-polling
property. This file remains historical context.
