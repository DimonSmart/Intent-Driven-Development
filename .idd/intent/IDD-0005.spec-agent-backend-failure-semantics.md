# IDD-0005.spec-agent-backend-failure-semantics

## Status

Superseded by IDD-0006

## Historical Intent

The former deterministic Factory runtime classified external Agent Backend
quota, rate-limit, authentication, transport, timeout, retry, and continuation
conditions as runtime-owned technical states.

## Superseded Semantics

The simplified Factory no longer owns backend failure classification, semantic
retry budgets, technical restart budgets, physical attempt persistence, or
backend continuation states.

If a native planner or worker does not return a trusted terminal result, Factory
leaves the pending task unchanged and stops the current invocation. Platform
errors are reported as platform errors rather than converted into Factory
workflow states.

This document remains only as history of the removed runtime contract. Current
Factory behavior is owned by IDD-0001 and IDD-0006.
