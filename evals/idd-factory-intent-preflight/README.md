# Factory Intent Preflight evals

These focused semantic cases evaluate the pre-runtime behavior of an explicitly
invoked `idd-factory-run`. Run them with an installed `idd-intent` and
`idd-factory` pair against isolated fixtures. The evaluator must observe intent
writes, runtime creation, the request stored in `request.md`, and the structured
outcome.

The cases intentionally separate missing documentation from missing product
decisions and verify that Intent Preflight reuses the ordinary intent ownership
workflows before Factory planning.
